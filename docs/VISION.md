# TPG FaceEngine

## Миссия

Профессиональная платформа для сопровождения и пополнения больших биометрических архивов, где оператор остается главным участником принятия решений, а система максимально ускоряет и объясняет свою работу.

## Цель

Создать инструмент, которым можно пользоваться каждый день на базах из 20 000+ фотографий, без зависаний, с понятным интерфейсом и возможностью расширения.

## Принципы

1. **Operator First** — любая функция должна помогать оператору быстрее и надежнее обработать фотографии
2. **Стабильное ядро** — Core не меняется без веской причины и ADR
3. **Архитектура > Функции** — сначала структура, потом фичи
4. **Прозрачность** — все решения объясняются, все действия логируются
5. **Расширяемость** — плагины, профили, темы, layouts
