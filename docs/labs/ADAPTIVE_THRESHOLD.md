# Adaptive Threshold

## Концепция

Adaptive Threshold — это динамический порог для принятия решения о совпадении, который подстраивается под качество фото, освещение, угол поворота и другие факторы.

## Проблема

Фиксированный порог `0.6` работает для хороших фото, но плохо для:
- Размытых снимков
- Фото под углом
- Слабого освещения
- Частично закрытых лиц

## Решение

Базовый порог корректируется на penalties:

```python
base_threshold = 0.6
blur_penalty = max(0, (100 - blur_score) / 100) * 0.1
angle_penalty = max(0, (yaw_angle - 30) / 60) * 0.1
size_penalty = max(0, (80 - face_size) / 80) * 0.1

adaptive_threshold = base_threshold + blur_penalty + angle_penalty + size_penalty
```

## Факторы

| Фактор | Влияние | Формула |
|--------|---------|---------|
| Blur | +0.0..0.1 | `max(0, (100 - score)/100) * 0.1` |
| Yaw | +0.0..0.1 | `max(0, (angle - 30)/60) * 0.1` |
| Pitch | +0.0..0.1 | `max(0, (angle - 20)/50) * 0.1` |
| Size | +0.0..0.1 | `max(0, (80 - size)/80) * 0.1` |
| Confidence | +0.0..0.05 | `max(0, (0.5 - conf)/0.5) * 0.05` |

## Преимущества

- Меньше ложных отрицаний для плохих фото
- Меньше ложных положительных для хороших фото
- Прозрачность: оператор видит, почему порог изменился
