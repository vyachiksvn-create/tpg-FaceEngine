# Smart Vote

## Концепция

Smart Vote — это стратегия выбора кандидата при поиске, которая учитывает не только максимальное совпадение, но и консенсус между несколькими фотографиями персоны.

## Проблема

Одна фотография может дать высокий score по случайному совпадению. Но если у персоны 10 фотографий и 8 из них показывают совпадение — это надёжнее.

## Решение

```
Для каждой персоны:
  score = Σ cosine_similarity(query, embedding_i) / count_i
  votes = count_i

Финальный score = 0.6 * max_score + 0.4 * (votes / max_votes)
```

## Алгоритм

1. Получаем Top-K от Faiss
2. Группируем по identity_id
3. Для каждой группы считаем:
   - Средний cosine similarity
   - Количество голосов (фото)
4. Применяем формулу Hybrid Score
5. Сравниваем с порогом

## Метрики

- **Precision@K** — точность в топ-K
- **MRR** — Mean Reciprocal Rank
- **Coverage** — доля найденных персон

## Сравнение со стратегиями

| Стратегия | Преимущество | Недостаток |
|-----------|-------------|------------|
| max | Простота | Уязвимость к шуму |
| vote | Устойчивость | Зависит от количества фото |
| hybrid | Баланс | Сложнее настроить |
