# Benchmark Lab

## Концепция

Benchmark Lab — это инструмент для сравнения производительности и точности разных моделей и настроек на одинаковых данных.

## Цель

Объективный выбор лучшей модели для конкретной базы.

## Метрики

- **Accuracy** — точность распознавания
- **Speed** — время на одно фото
- **Memory** — потребление RAM/VRAM
- **Coverage** — доля успешно обработанных фото

## Процесс

1. Выбрать набор тестовых фото (fixed dataset)
2. Выбрать модели для сравнения
3. Запустить Benchmark
4. Получить отчет

## Отчет
