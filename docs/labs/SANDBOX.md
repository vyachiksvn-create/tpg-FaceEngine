# Sandbox

## Концепция

Sandbox — это изолированная среда для экспериментов, которая не затрагивает основную базу данных и рабочие файлы.

## Цель

Безопасное тестирование новых моделей, параметров и пайплайнов.

## Особенности

- Отдельная БД (SQLite in-memory или временный файл)
- Отдельный Faiss индекс
- Отдельные логи
- Автоматическая очистка после сессии

## Использование

```python
with Sandbox() as sb:
    sb.import_photos("/test/photos")
    result = sb.search(photo)
    assert result.confidence > 0.8
# Все данные удалены
```
