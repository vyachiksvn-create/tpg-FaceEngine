# TPG Studio

## Концепция

TPG Studio — это отдельное приложение внутри проекта для экспериментов с алгоритмами, сравнения моделей и визуальной настройки пайплайнов.

## Цель

Позволить пользователю и разработчику:
- Сравнивать модели распознавания на одних и тех же данных
- Настраивать параметры без перезапуска основной программы
- Создавать и тестировать новые пайплайны
- Визуализировать результаты

## Запланированные модули

### Benchmark Lab
- Запуск нескольких моделей на одном наборе
- Метрики: accuracy, speed, memory
- Отчеты в HTML/JSON

### Sandbox
- Изолированная среда для экспериментов
- Без риска для основной базы
- Возможность отката

### Workflow Builder
- Визуальный конструктор пайплайнов
- Узлы: Load → Detect → Embed → Search → Decide
- Экспорт/импорт конфигураций

### Model Comparison
- Параллельный запуск моделей
- Табличное сравнение
- Визуализация различий

### Plugin Marketplace
- Каталог плагинов
- Установка одной командой
- Версионирование и зависимости

## Интеграция с Core

Studio использует те же интерфейсы, что и Desktop:
- EventBus
- PluginManager
- ProfileManager
- WorkspaceManager

Но работает в Sandbox-режиме, не затрагивая основной workspace.
