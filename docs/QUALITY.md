# Quality

Критерии качества TPG FaceEngine. Эти метрики не обсуждаются, они выполняются.

## Производительность

| Метрика | Цель v1.0 | Измерение |
|---------|-----------|-----------|
| Время открытия следующего фото | < 100 мс | Desktop → Next |
| От подтверждения до следующего фото | < 300 мс | Confirm → Next |
| Обработка одного фото | < 1 сек | Pipeline end-to-end |
| Импорт 1000 фото | < 15 мин | Импорт с SSD |
| Поиск Top-5 | < 50 мс | Faiss query |
| Память на 20k фото | < 4 GB | Peak RAM |

## UX

| Метрика | Цель v1.0 |
|---------|-----------|
| Количество действий на одно фото | ≤ 2 |
| Обработка без мыши | 100% |
| Горячие клавиши для всех действий | Да |
| Автопереход к следующему фото | Да |
| Отмена/прерывание любой операции | Да |

## Надёжность

| Метрика | Цель v1.0 |
|---------|-----------|
| Потеря данных при сбое | 0 |
| Автоматический backup | Да |
| История всех действий | Да |
| Откат операций | Да |
| Восстановление из backup | Да |

## Архитектура

| Правило | Обоснование |
|---------|-------------|
| Desktop не обращается к SQLite напрямую | Только через сервисы |
| Все длинные операции через JobManager | Без блокировки UI |
| Все действия через EventBus | Слабосвязанность |
| Core не зависит от Desktop | Направление зависимостей |
| Каждый модуль < 500 строк | Поддерживаемость |
| Каждая функция < 50 строк | Читаемость |

## Definition of Done

Sprint считается завершённым, если:
1. Все тесты проходят
2. Код проходит проверку стиля
3. Документация обновлена
4. Репозиторий синхронизирован с GitHub
5. Рабочий сценарий проходит без сбоев на 100 тестовых фото
