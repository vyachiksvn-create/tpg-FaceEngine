# IDEAS

Этот документ содержит все идеи, которые мы откладываем на потом.

Они не реализуются сейчас, но формализованы, чтобы не потеряться.

## Критерии попадания в релиз

Идея попадает в релиз, когда:
1. Есть стабильное ядро (Core + Storage + Recognition + Desktop)
2. Есть реальные пользовательские сценарии, требующие этой функции
3. Есть прототип или оценка сложности

## Как использовать этот документ

1. Каждая идея имеет статус
2. Приоритет определяется в ROADMAP.md
3. Идеи не удаляются, только переносятся
4. Любая идея может быть реализована раньше, если есть веская причина

## Правило

> "Пока проект не работает на реальных данных, новые идеи только записываются."
