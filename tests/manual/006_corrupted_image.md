# 006 Corrupted Image

## Цель
Проверить обработку битых изображений.

## Подготовка
- Положить битый/поврежденный файл в `D:\Base\x\`

## Шаги
1. Запустить импорт с битым изображением
2. Проверить результат

## Ожидаемый результат
- Программа не падает
- Бит файл пропускается
- Записывается в ImportLog со статусом error
- Показывается понятное сообщение

## Фактический результат
_Заполняется во время тестирования_

## Статус
⏳ Ожидает тестирования
