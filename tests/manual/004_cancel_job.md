# 004 Cancel Job

## Цель
Проверить отмену длительной операции.

## Подготовка
- Выполнен 001 Build Archive

## Шаги
1. Запустить импорт большой папки
2. Во время импорта нажать Cancel
3. Проверить состояние

## Ожидаемый результат
- Операция прерывается
- Часть данных сохранена
- Программа не падает
- Можно возобновить импорт
