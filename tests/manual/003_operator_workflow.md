# 003 Operator Workflow

## Цель
Проверить полный цикл обработки одной фотографии оператором.

## Подготовка
- Выполнен 001 Build Archive
- Запущен Desktop в Focus Mode

## Шаги
1. Открыть Workspace
2. Выбрать папку `D:\Base\x\`
3. Начать обработку
4. Для каждой фотографии:
   - Нажать Enter для подтверждения (если совпадение)
   - Или N для новой персоны
   - Или S для пропуска
5. Обработать 50 фото
6. Зафиксировать время и действия

## Ожидаемый результат
- Открытие следующего фото: < 100 мс
- От подтверждения до следующего: < 300 мс
- Действий на фото: ≤ 2
- Все действия записаны в History
- Backup создан
