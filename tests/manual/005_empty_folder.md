# 005 Empty Folder

## Цель
Проверить поведение при пустой папке.

## Подготовка
- Создать пустую папку `D:\Base\Empty\`

## Шаги
1. Запустить импорт пустой папки
2. Проверить результат

## Ожидаемый результат
- Программа не падает
- Показывает "0 фото"
- Завершается корректно

## Фактический результат
_Заполняется во время тестирования_
