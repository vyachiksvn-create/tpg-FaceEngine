# 001 Build Archive

## Цель
Проверить полный импорт базы известных персон.

## Подготовка
- `D:\Base\` содержит ~2000 фото в папках по персонам
- Workspace пустой

## Шаги
1. Создать Workspace `D:\FaceEngine_Test\Workspace\`
2. Указать Known Folder: `D:\Base\`
3. Запустить Build Archive
4. Дождаться завершения

## Ожидаемый результат
- Найдено персон: 400–800
- Найдено фотографий: ~2000
- Ошибок: 0–5
- Время: < 10 минут
- SQLite создана
- Faiss индекс создан
- Миниатюры сохранены

## Фактический результат
_Заполняется во время тестирования_
