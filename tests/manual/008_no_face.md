# 008 No Face Detection

## Цель
Проверить обработку фото без лиц.

## Подготовка
- Положить фото без лиц (пейзаж, текст, животное) в `D:\Base\x\`

## Шаги
1. Запустить обработку
2. Дойти до фото без лица
3. Проверить результат

## Ожидаемый результат
- Программа не падает
- Показывает "Лицо не обнаружено"
- Предлагает Skip/Delete
- Записывает в ImportLog

## Фактический результат
_Заполняется во время тестирования_
